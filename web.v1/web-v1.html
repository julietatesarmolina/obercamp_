CONOCÉ OBERCAMP

QUIÉNES SOMOS

OBERCAMP es un espacio de entrenamiento futbolístico creado para potenciar las capacidades de cada jugador. Buscamos que cada futbolista pueda desarrollar su máximo potencial, trabajando de manera específica sobre las necesidades que el juego exige.

QUÉ HACEMOS

Trabajamos para mejorar aspectos fundamentales del futbolista: precisión, potencia, pliometría, coordinación, velocidad y capacidad de movimiento, siempre buscando que cada ejercicio tenga una aplicación real dentro de la cancha.

DE QUÉ TRATA

Entrenamos con una metodología dinámica, progresiva y específica para el fútbol. Cada sesión combina intensidad, técnica y toma de decisiones.

No entrenamos solamente para estar en forma. Entrenamos para jugar mejor.
